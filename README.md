# Folder Structure Generator

Link: https://proparitosh.github.io/Folder-Structure-Generator-for-Projects/

Shorten Link: https://bit.ly/foldergenerator

A simple client-side folder structure generator. Choose a preset, customize the hierarchy, and download it as a ZIP.

## Features
- Preset folder structures
- Add, rename, delete, reorder and nest folders
- Auto-numbering
- ZIP download with empty folders preserved
- No login, signup, backend, database, or file upload

## Run locally
Open `index.html` in a browser.

## Tech
- HTML
- CSS
- Vanilla JavaScript
- JSZip
